# RUH Flights Big Data Analytics

## Overview

This project applied **Apache Spark and Scala** to analyze more than **153K flight records** associated with Riyadh air traffic.

The project covered distributed preprocessing, exploratory analysis, advanced Spark SQL queries, and machine-learning workflows.

## My Contribution

I independently implemented the project's **Spark ML phase**, including:

- Feature preparation
- ML pipeline construction
- Random Forest training
- Baseline comparison
- Model evaluation
- Result interpretation

I also contributed to:

- Data cleaning
- Outlier handling
- Refinement of earlier processing stages
- Final analysis and project integration

## Big Data Analysis

The broader project used:

- Spark RDDs
- Spark DataFrames
- Spark SQL
- Window functions
- Traffic and peak-period analysis
- Airline and destination analysis

## Machine Learning

A Random Forest classifier was implemented using Spark ML.

The final revised experiment achieved approximately:

- **92.35% test accuracy**
- **0.958 ROC-AUC**

## Tech Stack

Apache Spark · Scala · Spark SQL · RDDs · Spark MLlib · Random Forest
